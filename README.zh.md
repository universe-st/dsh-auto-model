# dsh-auto-model · 切模插件

[English](README.md) | [中文](README.zh.md)

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）提供「自切模型」。自切模型不是真实模型：它是一条具名路由，把发往它的每个请求按顺序匹配的**切换规则**转发给真实提供商/模型。模型选择器中它会出现在提供商 **切模插件**（`auto-model`）下。

```
对话 → auto-model / auto → 命中规则 → deepseek / deepseek-v4-pro
                        ↘ 未命中   → 兜底：kimi / kimi-k2
```

## 用它做什么

- **峰谷计价**：不同提供商在不同时段有折扣。单日时间范围规则可以在便宜时段把请求转到优惠提供商，时段结束后再切回更强的模型，且无需改动会话中选择的模型。
- **额度耗尽兜底**：针对 `QUOTA` / `ACCOUNT_QUOTA` 的「当前模型近期失败」规则，可以在主提供商额度耗尽后把流量切到备用提供商，让这一轮对话继续完成。
- **提供商不稳定**：当某个提供商在**自身自动重试之后**仍然超时或限流时，路由器会切换到备用线路，而不是让这一轮失败。
- **按任务分流**：用首条消息或最近消息中的关键字（`debug`、`设计`、`长文`）选择不同模型；识图任务也可以自动转给视觉模型。
- **依赖外部状态**：命令规则可以读取任意 shell 命令的输出（`git branch --show-current`、标志文件、代理状态），据此选择模型，并带缓存时长，避免每次请求都付出命令开销。

## 功能

- 可配置多个自切模型，每个都有自己的有序规则与必填的兜底模型。
- 七种规则：单日时间范围、跨天日期时间范围、首个用户对话关键字、最近用户对话关键字、试图识图、命令输出匹配、当前模型近期失败。
- 规则可拖拽排序，优先级从上到下；命中最高优先级后不再检测其它规则。
- 透明恢复：失败目标先按**真实模型自身的重试配置**重试，再用尽后切换。对上层逻辑只呈现一个结果，或最终失败。
- 在 LLM 流边界转发请求，真实线路会保留它自己的适配器、重放状态、图片处理与工具投影。
- 会话列表悬浮卡里有一行仅用户可见的小字，说明当前真正在回答的真实模型，模型不可见。
- 配置页面位于**插件**页内，模型选择器直接读取实时模型目录，也可手动填写提供商/模型。

## 安装

本插件是一个 DSH bundle，直接安装目录：

```sh
dsh plugin --profile <你的 profile> add /绝对路径/dsh-auto-model
```

或在 **插件 → 添加插件 → 本地目录**。

也可以直接从 GitHub 安装：

```sh
dsh plugin --profile <你的 profile> add github:universe-st/dsh-auto-model
```

bundle 列表变化后重启 DSH，然后在**插件**页启用「切模插件」。

要求：DSH `>=0.2.2-rc.3 <0.3.0-0`（已在 `engines.dsh` 中声明，版本不符时安装会被拒绝，而不是装上后静默坏掉），并包含 `llm` 与 `sessionProjections` 服务（标准部署均具备）。

## 配置

1. **插件 → 切模插件 → `auto-model` 行 → 配置**。
2. **添加自切模型**：填写模型 ID（显示为 `auto-model/<ID>`）、显示名称，并选择兜底真实模型。
3. 添加规则，为每条规则选择命中后使用的真实模型。
4. 保存。模型会出现在输入框的模型选择器中，分组为**切模插件**。

可选的**能力参考模型**决定对外声明的上下文窗口、输出上限、推理档位与图片支持，默认跟随兜底模型。若混用不同厂商，建议把它指向与主要目标协议一致的模型。

### 规则

| 规则 | 命中条件 |
|---|---|
| 单日时间范围 | 请求时间落在半开区间 `[from, to)` 内；支持跨午夜（`from = to` 表示全天）、部分星期与 IANA 时区。 |
| 跨天日期时间范围 | 请求时间处于两个确切日期时间之间。 |
| 首个用户对话包含关键字 | 会话的第一条用户消息包含任一关键字。 |
| 最近用户对话包含关键字 | 最近 N 条用户消息中任意一条包含任一关键字。 |
| 试图识图 | 请求携带图片，或历史中调用过识图工具（`read_image`、`screenshot` 等，可配置）。 |
| 命令输出匹配 | 配置的 shell 命令输出与期望值匹配（等于/包含/正则/不等于），带缓存时长。 |
| 当前模型近期失败 | 当前使用的模型在最近 N 小时内以指定失败码失败过（留空表示任意失败码），且自动重试已用尽。 |

请把「当前模型近期失败」规则放在时间/关键字规则**上方**。选择会在第一条命中规则处停止，若上方有一条始终命中的时间规则，切换时会再次选中已经失败的模型，只能退回兜底模型。

## 重试与切换

- 重试在请求内部完成，遵循真实提供商自身解析出的重试策略与退避，并尊重 `Retry-After`。
- `Retry-After` 即使长于本地退避上限也会被尊重；但若这段等待超出剩余 `retryBudgetMs`，会立刻放弃该目标并选择下一个，请求不会睡过自己的预算。
- 在产生可见内容之前，什么都不向上层输出，因此重试与切换对上层是隐藏的。
- 某个目标的重试用尽后，会带着这条失败记录重新执行规则选择——此时「当前模型近期失败」规则可以接管。配置的兜底模型是最后防线。
- 已经输出可见内容之后再失败，无法在不重复输出的前提下重试，会如实作为失败上报。
- `retryBudgetMs`（默认 90 秒）限制单个目标的重试时长，`0` 表示不设时间上限；`maxSwitches` 限制单次请求的切换次数。

### 状态与重启

路由记忆（当前真实目标与失败账本）保存在插件进程里，不写入会话日志。DSH 重启后账本为空，**当前模型近期失败**规则会先按兜底模型作答，直到记录到新的失败；会话列表提示会清空，并在下一次请求后重新出现。请求本身不依赖这份记忆：规则匹配、重试与切换都会按请求重新计算。

## 会话列表提示

会话行的悬浮卡会显示一行小字：当前自切模型真正在使用的真实模型。数据来自插件内存并镜像到 Session projection，仅用户可见，不写入模型可见日志。当会话直接切换到真实模型时，这行提示会自动消失。

## 安全

命令规则会以你的用户权限在 Host 上执行 shell 命令。只配置你自己愿意执行的命令。命令依赖 POSIX shell（`/bin/sh`），在 Windows 上不会执行。

## 开发

```sh
node --test "test/*.test.js"
```

规则引擎、请求路由与配置归一化都是不依赖 DSH 的普通模块，可直接用 Node 运行测试；bundle 本身由 DSH 加载。
